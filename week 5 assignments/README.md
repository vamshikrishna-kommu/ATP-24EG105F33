# Week 5 Assignments: Advanced UI & React Introduction

This folder contains a mix of advanced CSS layout assignments and the first steps into building React applications.

## Assignments Overview

### CSS Layout & Design
| Folder | Topic | Description |
| :--- | :--- | :--- |
| `assignment-4` | Landing Page | A responsive landing page design using Flexbox. |
| `assignment-5` | Cards Layout | Modern UI cards with hover effects and responsive grids. |
| `assignment 6` | Libertarian Landing | A themed landing page demonstrating consistent branding and grid layouts. |
| `assignment 7` | UI Components | Practice with complex navigation menus and hero sections. |
| `tables` | Data Tables | Semantic HTML tables with advanced CSS styling for readability. |

### React Applications
| Folder | Topic | Description |
| :--- | :--- | :--- |
| `react-app-1` | E-commerce Store | A React app displaying products from an API-like source, featuring a Counter component. |
| `react-app-2` | Product Filter | An interactive app for filtering and searching through a list of products. |

## Key Enhancements
- **Refactored React Code**: Cleaned up `App.jsx` by separating data and logic into modular components.
- **Modern CSS**: Ensured all UI assignments use Flexbox/Grid for responsiveness.
- **Premium Aesthetics**: Enhanced color palettes and typography for a professional look.
- **Documentation**: Added usage instructions and feature lists for each React project.

## How to Run React Apps
1. Navigate to the specific project folder (e.g., `react-app-1`).
2. Install dependencies: `npm install`
3. Run the development server: `npm run dev`
