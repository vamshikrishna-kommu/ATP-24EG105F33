# Week 1 Assignments: JavaScript Basics

This folder contains a collection of fundamental JavaScript scripts focusing on array manipulations, functions, and basic logic operations.

## Assignments Overview

| File | Description | Key Concepts |
| :--- | :--- | :--- |
| `array_operations.js` | Basic CRUD operations on an employee array. | `splice`, `find`, `findIndex` |
| `big_num_in_two.js` | Compares two numbers to find the largest. | Conditionals, Template Literals |
| `big_num_in_three.js` | Compares three numbers to find the largest. | Logic Operators, Conditionals |
| `big_num_in_function.js` | Function to return the largest of three numbers. | Arrow Functions, `Math.max` |
| `smallest_element_in_array.js` | Finds the smallest value in a numeric array. | Spread Operator, `Math.min` |
| `sum_of_marks.js` | Calculates the total of an array of marks. | `Array.reduce` |
| `sum_of_function.js` | A reusable function to sum any numeric array. | Functions, `Array.reduce` |
| `search_in_array.js` | Searches for an element and returns its index. | `Array.indexOf` |
| `rest_operator1.js` | Sums any number of arguments using the rest operator. | Rest Parameters, `Array.reduce` |

## How to Run

Ensure you have [Node.js](https://nodejs.org/) installed, then run any script using:

```bash
node <filename>.js
```

Example:
```bash
node array_operations.js
```

## Code Standards
All scripts have been enhanced to:
- Use **ES6+ syntax** (`const`/`let`, arrow functions, template literals).
- Implement **modern array methods** (`reduce`, `find`, `indexOf`).
- Include **JSDoc comments** for better readability and maintainability.
