# Week 2 Assignments: Intermediate JavaScript & Backend

This folder contains advanced JavaScript concepts and the first steps into backend development with Express.js.

## Assignments Overview

### JavaScript Advanced Concepts
| File | Topic | Description |
| :--- | :--- | :--- |
| `array_advanced1-8.js` | Array Methods | Real-world scenarios using `map`, `filter`, `reduce`, `find`, and `findIndex`. |
| `class1.js` | ES6 Classes | Implementation of a Library Book Management System using OOP. |
| `shallow_copy1.js` | Object Copying | Demonstrates spread operator and shared references in nested objects. |
| `deep_copy1.js` | Object Copying | Demonstrates `structuredClone()` for complete object isolation. |
| `spread_operator1-2.js` | Spread Operator | Exercises on cloning and extending arrays and objects. |
| `timer_functions1-2.js` | Async JS | Simulating an Exam Portal and OTP Countdown using `setTimeout` and `setInterval`. |

### Backend Development
| Folder | Topic | Description |
| :--- | :--- | :--- |
| `backend1/` | Express.js | A basic REST API with User and Product management. |
| `modules1/` | ES Modules | Practice with `import` and `export` statements. |
